# Changelog

All notable changes to AppSweep will be documented in this file.

## [0.1.0] - 2026-08-01

### Added

- Native GTK 4 and Libadwaita interface
- APT desktop-application discovery
- Snap application discovery
- Flatpak application discovery
- APT package-removal analysis
- Snap removal with or without a new snapshot
- User and system Flatpak removal
- Verified rollback backups for application data
- Permanent removal without backup
- PolicyKit-based privileged helper
- Protection for critical APT packages
- Protection for Snap runtime and platform components
- Debian package and desktop integration
